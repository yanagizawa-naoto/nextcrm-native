# NextCRM Native

**Apple Silicon / macOS 13以降向け。Swift・AppKit・SQLiteで作った、個人用の日本語CRMです。**

**営業対象10,000件を保存した最終版で、起動後の一覧表示は約49 MBを実測しました。** メモリの値は特定時点の観測です。常時の使用量や最大値を保証するものではありません。[測定条件と内訳](docs/MEMORY.md)

[NextCRM](https://github.com/pdovhomilja/nextcrm-app) をもとにした非公式のMacネイティブ派生プロジェクトです。原著プロジェクトとの提携・公式サポートを示すものではありません。このリポジトリの目的はネイティブ版です。元Web版のコードも、ビルド時の生成処理と原典との動作比較のために含みます。

主な機能は次のとおりです。

- 取引先、連絡先、見込み客、商談、営業対象リスト
- 商品・価格表、受注・契約、請求書・入金・PDF
- プロジェクト、カンバン、タスク、コメント、関連文書
- 文書の版管理、本文抽出、プレビュー、検索
- メール、Googleカレンダー、Calendly、キャンペーン、HTMLテンプレート
- レポート、CSV/XLSX入出力、営業の自動処理
- AI要約・分類・情報補完、MCP API、Odoo/OXOなどのプラグイン
- バックアップ・復元、旧処理の確認と外部連携の段階的な再開

この版の利用範囲は、**本人1人・1台のMac**です。実行時にNode.js、Webサーバー、PostgreSQLは不要です。外部連携には、利用するサービスのアカウントと接続設定が必要です。

## ビルドして使う

Apple SiliconのMac、Xcode 26.5相当の開発環境（Swift 6.3系、macOS SDK 26.5）、Python 3、Node.js 22.13.0以降（推奨：24 LTS）、pnpm 11.20.0が必要です。ビルド時の生成処理は、ロックファイルに固定したTypeScriptなどのNode依存を使用します。

リポジトリ直下で実行します。

```sh
pnpm install --frozen-lockfile --ignore-scripts
zsh desktop/native/build.sh
```

初回の依存導入にはネットワークを使用します。準備後の通常のビルドは依存をダウンロードしません。

出力先は `desktop/native/build/NextCRM Native.app` です。依存関係の準備、署名、確認手順は[ビルド手順](docs/BUILDING.md)を参照してください。操作方法は[使い方](desktop/native/使い方.txt)にあります。

## メモリ測定

MBは **1 MB = 1,000,000バイト**で表記しています。

| 構成・操作 | 実測値 | 測定対象 |
| --- | ---: | --- |
| 最終版：10,000件を保存して起動後、一覧を表示 | **約49 MB** | アプリ本体 |
| 直前版：10,000件のCSV取り込み中 | 約139 MB | アプリ本体 |
| 直前版：HTMLプレビュー表示中 | 約122 MB | 本体・表示ヘルパー・WebKitの合計 |

最終版は453 Swiftソース、直前版は449 Swiftソースの構成です。同じ本体ソースを用いる隔離検証ビルドと合成データで測定しました。HTML表示を閉じた際には、表示ヘルパーとWebKitの4プロセスが終了することを確認しています。測定値はRSSではなくphysical footprintです。[詳細](docs/MEMORY.md)

## 検証範囲

保存・再起動、日本語入力、文書の関連付け、10,000件のCSV取り込み、バックアップ・復元などを隔離環境で確認しています。最終統合では、復元後のメール・Google予定の確認処理について433チェックが通過しています。

実アカウントによる外部サービス通信や、本番の旧Web環境からのデータ移行は未検証です。保護した表・画像・独自HTMLはHTMLソースで編集し、元Web版と完全に同一のWYSIWYG・JSON互換性は保証しません。詳しくは[検証と制限](docs/VERIFICATION.md)を参照してください。
