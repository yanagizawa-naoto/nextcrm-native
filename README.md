# NextCRM Native

**Apple Silicon / macOS 13以降向け。Swift・AppKit・SQLiteで作った、個人用の日本語CRMです。**

**営業対象10,000件を保存した一覧の待機時は、前面表示で約64.5 MB、バックグラウンドで約68.5 MBを実測しました（関連プロセス込み）。** 各条件3回起動した中央値です。常時の使用量や最大値を保証するものではありません。[測定条件と内訳](docs/MEMORY.md)

[NextCRM](https://github.com/pdovhomilja/nextcrm-app) をもとにした非公式のMacネイティブ派生プロジェクトです。原著プロジェクトとの提携・公式サポートを示すものではありません。このリポジトリの目的はネイティブ版です。元Web版のコードも、ビルド時の生成処理と原典との動作比較のために含みます。

主な機能は次のとおりです。

- 取引先、連絡先、見込み客、商談、営業対象リスト
- 商品・価格表、受注・契約、請求書・入金・PDF
- プロジェクト、カンバン、タスク、コメント、関連文書
- 文書の版管理、本文抽出、プレビュー、検索
- メール、Googleカレンダー、Calendly、キャンペーン、HTMLテンプレート
- レポート、CSV/XLSX入出力、営業の自動処理
- AI要約・分類・情報補完、MCP API、Odoo/OXOなどのプラグイン
- バックアップ・復元、旧処理の確認と外部連携の段階的な再開

この版の利用範囲は、**本人1人・1台のMac**です。実行時にNode.js、Webサーバー、PostgreSQLは不要です。外部連携には、利用するサービスのアカウントと接続設定が必要です。

## 自分のアカウントで接続する

メニューまたは左側の「アカウントを接続…」から、Googleメール、Googleカレンダー、ChatGPTを選べます。接続しなくても顧客・商談などのローカル管理は利用できます。

- **Googleメール・カレンダー**：配布元のGoogleアプリ登録を同梱したビルドでは、利用者はブラウザでログインして権限を許可します。現在のソースには実際の配布用クライアントIDを同梱していません。一般公開には配布元の登録・必要な審査が残っています。
- **ChatGPT**：対応する本人のChatGPTプラン・クレジットで、手動の要約・文章作成とメールテンプレートのAI作成を利用する接続を実装しています。利用可否・モデル・上限は本人のアカウントとワークスペースに従います。実アカウントでの一連の動作は未検証です。
- **APIキー方式**：各利用者のAPIキーを設定する従来方式も選べます。検索用の埋め込みや企業調査など、ChatGPT接続が対応しない機能には別途API・サービス設定が必要です。ChatGPTの失敗時に、有料APIへ自動で切り替えることはありません。

AIの利用料は各利用者が自分の契約で負担します。配布元の共用キーは使いません。認証情報は各Macのキーチェーンに保存します。[配布元の準備と接続の詳細](docs/DISTRIBUTION.md)

## ビルドして使う

Apple SiliconのMac、Xcode 26.5相当の開発環境（Swift 6.3系、macOS SDK 26.5）、Python 3、Node.js 22.13.0以降（推奨：24 LTS）、pnpm 11.20.0が必要です。ビルド時の生成処理は、ロックファイルに固定したTypeScriptなどのNode依存を使用します。

リポジトリ直下で実行します。

```sh
pnpm install --frozen-lockfile --ignore-scripts
zsh desktop/native/build.sh
```

初回の依存導入にはネットワークを使用します。準備後の通常のビルドは依存をダウンロードしません。

出力先は `desktop/native/build/NextCRM Native.app` です。依存関係の準備、署名、確認手順は[ビルド手順](docs/BUILDING.md)を参照してください。操作方法は[使い方](desktop/native/使い方.txt)にあります。

## メモリ測定

MBは **1 MB = 1,000,000バイト**で表記しています。2026年11月26日（日本時間）、同じMac・同じ合成データ10,000件・同じ画面内容領域で測定しました。各値は3回の独立した起動それぞれで5点測定し、起動ごとの中央値をさらに中央値にしたものです。

この測定はアカウント接続機能を追加する前の453ソース版です。今回の追加後のメモリ使用量は再測定していません。

| 一覧を表示した状態 | 保存済みの軽量化Web版 | Native版 | 参考削減率 |
| --- | ---: | ---: | ---: |
| バックグラウンド（macOSの「隠す」） | 560.2 MB | **68.5 MB** | **87.8%** |
| 前面表示（アクティブ・画面上に表示） | 655.9 MB | **64.5 MB** | **90.2%** |

**比較上の制約：Web版にはInngestの内部送信で認証エラーが残っています。** 一覧・検索・詳細は動作していますが、バックグラウンド処理が完全に正常なWeb版との比較ではないため、削減率は今回の保存済み環境に対する参考値です。上流の未改変版や初期のVM構成との比較ではありません。

Nativeは本体と関連ヘルパー、Webは画面・WebKit・Node.js・Inngest・PostgreSQLと関連ヘルパーを含むphysical footprintです。共有OSプロセス（WindowServerなど）は含みません。10,000件は保存件数で、1ページの表示件数は製品の既定値（Native 100件、Web 10件）のままです。前面とバックグラウンドは別時刻の実験であり、この差から表示状態の効果は断定できません。

以前の約49 MBはアプリ本体だけを測った単発の値で、今回の合計値とは測定範囲が異なります。[条件・全試行の内訳と過去の測定](docs/MEMORY.md) / [採用した全60サンプル（JSON）](docs/verification/memory-comparison-20261126.json)

## 検証範囲

保存・再起動、日本語入力、文書の関連付け、10,000件のCSV取り込み、バックアップ・復元などを隔離環境で確認しています。最終統合では、復元後のメール・Google予定の確認処理について433チェックが通過しています。

実アカウントによる外部サービス通信や、本番の旧Web環境からのデータ移行は未検証です。保護した表・画像・独自HTMLはHTMLソースで編集し、元Web版と完全に同一のWYSIWYG・JSON互換性は保証しません。詳しくは[検証と制限](docs/VERIFICATION.md)を参照してください。
