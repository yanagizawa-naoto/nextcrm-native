## HTML character-reference table

`desktop/native/CampaignHTMLEntities.inc` is generated by
`desktop/native/generate-campaign-entities.py` from Python's
`html.entities.html5` standard-library table. The generator changes each mapped
Unicode value to hexadecimal numeric character references. The upstream Python
module documents the HTML5 named-character-reference table as its data source.
The local Python distribution's full license notices are preserved in
[licenses/Python-LICENSE.txt](licenses/Python-LICENSE.txt). This is an attribution
for the generated table; the native application does not bundle a Python runtime.

## System libraries and build/test dependencies

The native build links macOS system frameworks and system SQLite, libxml2 and
libcurl. Their implementations are not vendored into this repository. JavaScript
build tools and original-source regression tests use the packages pinned in
`pnpm-lock.yaml`; each package retains its own license. `node_modules`, downloaded
package caches and compiled application artifacts are excluded from this source
snapshot. Do not describe all dependencies as MIT-licensed.
