# 復元後の送信結果確認テスト

Apple Silicon の macOS 13 以降で、既存の Xcode または Command Line Tools と Python 3 を使用します。追加パッケージ・Node・外部サービスのアカウントは不要です。ツールやSDKのダウンロードは行いません。

リポジトリのルートで実行してください。任意の作業ディレクトリからスクリプトのパスを指定しても実行できます。

```sh
python3 desktop/native/test-provider-review.py
```

`desktop/native/ApplicationSources.json` の全本体ソースを、一度だけテスト用共有ライブラリにビルドします。同じライブラリに対して以下を実行し、最後に `NativeDatabase.swift` と `MailReview.swift` の単独型検査も行います。

| テスト | 確認数 | 主な対象 |
| --- | ---: | --- |
| SMTP復元レビュー | 52 | 送信済み・未送信・結果不明の保留、旧IDの再送防止、ローカル保存、取消、通常SMTP経路 |
| Google復元レビュー | 45 | 復元先・本人・旧行を確認した結果記録、復元前の処理の再実行防止 |
| Google保留範囲 | 61 | 同じ予定やリモートIDへの重複操作の防止、無関係な新しい処理、再接続後の保留 |
| 既存の通知メールレビュー | 275 | 13種類の通知、結果確認、権限・期限・生データの競合、取消とAppKitの操作 |
| **合計** | **433** | |

SQLite、バックアップ／復元候補、個人用データへの紐付け、隔離、画面コントロールは実装本体を使用します。メール／Googleの通信と認証情報は合成fixtureです。実プロバイダーの送信結果、Keychain、通常のアプリデータを検証したという意味ではありません。復元の起動記録はテスト用に構成するため、このテストだけで実Appのプロセス引き継ぎやすべての機能の動作を確認したとは扱いません。AppKitを使用するため、ログイン済みのmacOS GUIセッションで実行してください。既存画面テストで一時的にテスト用パネルが表示されることがあります。

テストプロセスはネットワーク、Keychain、通常の `NextCRMNative` / `NextCRM` アプリデータへのアクセスを拒否するsandbox内で動きます。テスト用DBは実行ごとの一時フォルダに作成し、成功・失敗・中断時に回収します。コンパイルキャッシュも最後に削除します。ログ、共有ライブラリ、テスト実行ファイル、入力ハッシュは `desktop/native/build/provider-review-tests/` に残ります。`latest.json` が直近の `verification.json` を指します。ビルド出力は共有せず、不要になったらこのディレクトリを削除できます。

`provenance.json` は既存テストからの変更を記録したものです。テスト判定は変更せず、共有モジュール名とリポジトリ内のリソース／一時フォルダ指定だけを調整しています。`ExistingGooglePushSupport.swift` は既存の補助コードを保持しており、同梱の原典参照JSONを使う追加の `policy` 関数は、この433チェックでは実行しません。
