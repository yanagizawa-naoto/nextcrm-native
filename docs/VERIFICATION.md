# 検証と制限

この版は、本人1人が1台のMacで使う構成を対象にしています。複数端末での同時編集、共有サーバー、利用者招待・遠隔ログインを提供する版ではありません。移行データに含まれる過去の利用者・担当・監査記録は、個人用にするために消去したり一律管理者に変更したりせず保持します。

## 確認した範囲

最終構成は453 Swiftソースです。2026年11月25日に最適化した通常版・隔離検証版をビルドし、署名検査を通過しました。

- 最終版の統合検証：復元後のSMTP確認52、Google確認45、Googleの継続保留61、既存送信確認275の計433チェック。実SQLite、合成バックアップ・復元、コントローラーを使用しています。
- 最終版の実画面：10,000件の保存済み営業対象一覧、日本語の末尾データ検索、連携設定とバックアップ・復元準備の表示、通常終了を確認しました。
- 直前の449ソース構成：初回の個人用初期化、取引先・事例候補・プロジェクト・タスクの保存と再表示、文書の取り込み・関連付け・解除、テンプレート保存とHTML表示、10,000件CSV取り込みと再起動後の保持を確認しました。
- 日本語本文は320,000文字・920,000バイトを保存し、内容の一致を確認しました。

機能別の検証を積み重ねたうえで、最後の変更を同じ統合本体で再検証しています。過去の全テスト構成を最終版で一括再実行した、または元Web版の全操作・全入力との完全一致を証明した、という意味ではありません。

公開snapshotでも `python3 desktop/native/test-provider-review.py` で同じ433チェックとDB単独の型検査を再実行できます。実データ・ネットワーク・Keychainへのアクセスを拒否した一時領域で実行します。

## 外部サービスと移行

メール、Google、Calendly、Odoo、OXO、AIなどは、合成応答や隔離したサービス境界で検証しています。利用者の実アカウント、公開HTTPS受信窓口、実際の配信先を使う接続検証は行っていません。利用するサービス側の登録・認証・接続設定が必要です。

旧Web版のDB・ファイル・暗号化された認証情報を引き継ぐための処理は実装しています。本番の旧環境を用いた移行は未検証です。取得できないファイル、任意の外部URL、分類できないデータは自動的に破棄せず、確認待ちとして保持します。

復元直後は旧処理の外部送信を再開しません。確認や保留の記録、接続設定の確認、機能グループの明示的な再開を分けています。結果不明のGoogle予定は、対象範囲への書き込みを保留したまま扱います。確認画面の記録自体が、Google側での成功や未反映を検証するものではありません。

## 互換性と未測定の操作

- 保護した表・画像・独自HTMLはHTMLソースで編集します。元Web版と同一のWYSIWYG操作や、外部へのJSONだけの受け渡しによる完全な互換性は保証しません。
- 移行したレポート予定にタイムゾーンがない場合は、確認・保存が必要です。通貨コードには大文字の制約があります。
- カンバンの移動処理と保存は検証しましたが、OSの実ポインタードラッグ操作は未確認です。
- OCRによる画像・スキャンPDFの文字認識は提供していません。文字を含むPDF、テキスト、Wordの本文抽出とは別です。
- メモリ値は有限の操作とデータでの観測です。長時間の最大値や、全機能を同時使用した上限ではありません。[測定条件](MEMORY.md)
