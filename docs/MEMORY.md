# メモリ測定

READMEの主表示は10進のMBです。**1 MB = 1,000,000バイト**、参考として併記する **1 MiB = 1,048,576バイト**です。

## 結果

2026年11月25日のApple Silicon向け最適化ビルドを、合成データの隔離環境で測定しました。環境はApple M2、メモリ17.2 GB、macOS 26.6.2です。

| 測定した構成 | 操作 | バイト数 | MB | MiB（参考） |
| --- | --- | ---: | ---: | ---: |
| 最終版・453 Swiftソース | 10,000件を保存して起動後、営業対象一覧を表示 | 49,497,072 | 49.50 | 47.20 |
| 直前版・449 Swiftソース | 10,000件CSVの取り込み中 | 139,232,264 | 139.23 | 132.78 |
| 直前版・449 Swiftソース | HTMLプレビュー表示中の合計 | 121,802,856 | 121.80 | 116.16 |

READMEでは、それぞれ約49 MB・約139 MB・約122 MBと丸めています。機械可読の値は[measurements.json](measurements.json)にも記載しています。

HTMLプレビューの測定対象は、アプリ本体、表示ヘルパー、WebContent、GPU、Networkingの計5プロセスです。複数PIDを一度の`footprint`呼び出しに渡した合計値を使用し、個別値の単純加算ではありません。表示を閉じると、表示ヘルパーとWebKitの計4プロセスが終了することを確認しています。

## 条件と読み方

- macOSの`footprint`によるphysical footprintです。RSSとは異なる指標です。
- 最終版の49.50 MBは、アプリ本体1プロセスの特定時点の値です。全機能・全外部ワーカーを同時に動かした状態ではありません。
- 測定には同じSwift本体ソースを使う隔離検証ビルドを使用しました。実データや実サービスの認証情報は使用していません。
- 449版の取り込み・HTML測定を、453版で再測定した値として扱っていません。
- WindowServerなど、共有OSプロセスの消費量は含みません。
- 常時の使用量、長時間運用の最大値、データ量にかかわらない上限を示すものではありません。大きい添付・画像、検索、外部連携、同時操作により増減します。

初期化済みのキャッシュ、OSの状態、表示内容、データ量が異なるため、異なる場面の値だけでメモリ削減率を比較することはできません。
